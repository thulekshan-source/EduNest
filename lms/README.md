# LMS – ATI Batticaloa (PHP + MySQL)
1. Install XAMPP; start Apache and MySQL.
2. Copy this `lms` folder into `C:\xampp\htdocs\`.
3. Open http://localhost/phpmyadmin → Import → choose `database.sql`.
4. Open http://localhost/lms
5. Admin login: admin@lms.test / Admin@123 (change it). Students/teachers register themselves.
Open the folder in VS Code (File → Open Folder). SRS is in `SRS.md`.
